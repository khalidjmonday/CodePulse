# CodePulse

CodePulse is a Java-based developer assistant that analyzes source code projects and generates useful statistics.

## Features

- Scans Java projects
- Detects Java source files
- Counts total lines
- Counts code lines
- Counts blank lines
- Generates project reports
- Provides project statistics

## Technologies

- Java
- File Handling
- OOP Concepts
- Git
- GitHub

## Project Structure

src/
├── Main.java
├── ProjectScanner.java
├── LineCounter.java
├── ProjectStats.java
└── ReportGenerator.java

```text

Total Lines: 176
Code Lines: 114
Blank Lines: 62
```
